# Stage 0 Cut 0 — Continuous World Foundation

Status: implemented and focused-contract tested. This is **Cut 0 only**. It is
not certification of the later Stage 0 mountain, watershed, ecology, opening,
camp, deposit, or persistence cuts.

## What this cut changes

Cut 0 makes the existing authoritative terrain path safe to build later Stage 0
work on top of:

- Visible detailed terrain and player grounding use the same sampled
  FableScript matter surface.
- Detailed height is a residual on the continuous visible terrain carrier; it
  is not a second diagnostic plane or a replacement bowl.
- No tan safety/fallback slab is admitted into the playable path.
- The player-centred detailed obligation is isotropic: 3×3 P0 support, then
  complete ring 2 and ring 3 coverage in every direction.
- Velocity and camera prediction start only after the nearer concentric
  obligation and extend beyond it at normal 24 m/s traversal speed.
- Equal-distance packages have equal priority and protection. Eviction removes
  the farthest packages first.
- Coarse/previous terrain remains visible until every desired replacement tile
  is actually publishable. The old set retires only after the new set is ready,
  preventing a temporary sky gap during an LOD handoff.
- The launcher cleans up only an authority process proven to belong to its own
  prior session. It never kills an arbitrary process merely because a port is
  occupied.

No world-generation law, geology, water, ecology, material behavior, or
rendering style was changed in this cut.
